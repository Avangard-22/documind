КАК ПОЛУЧИТЬ DOCUMIND.EXE

Важно: этот архив содержит исходники и workflow сборки, а не готовый EXE.
Сборка Windows EXE выполняется на Windows runner GitHub Actions.

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте архив и загрузите ВСЁ содержимое папки DocuMind_Test_Build_0.1 в корень репозитория (включая скрытую папку .github).
3. Откройте вкладку Actions репозитория.
4. Выберите "Build DocuMind Windows EXE" и нажмите "Run workflow".
5. Дождитесь успешного завершения job. Если тесты или сборка упадут, откройте журнал шага с ошибкой.
6. В завершившемся запуске скачайте artifact "DocuMind-Windows-x64". Внутри будет DocuMind.exe.

Примечание: workflow сначала запускает тесты. Если они не пройдут, EXE не будет опубликован.
Этот способ требует аккаунта GitHub и загрузки проекта в ваш репозиторий.
Сборка и запуск GUI на реальном пользовательском компьютере здесь не проверены.
