# DocuMind Test Build 0.1

Тестовый исходный пакет настольного приложения для Windows 10/11.

## Что реализовано
- Графический интерфейс на Tkinter.
- Рекурсивный поиск PDF, DOCX и XLSX.
- Извлечение текста из текстовых PDF, DOCX и XLSX.
- Локальные правила на регулярных выражениях и редактор правил.
- SQLite-база истории обработки.
- Экспорт в XLSX: повторная обработка обновляет строку по полному пути документа.
- Проверка кэша по SHA-256, журналирование, отмена между документами.
- Автоматические тесты базовых функций.

## Требования
- Windows 10/11.
- Python 3.11 или 3.12 для запуска из исходников.
- Для чтения форматов установите зависимости.

## Первый запуск из исходников
1. Распакуйте ZIP в обычную папку, например `C:\Tools\DocuMind`.
2. Откройте PowerShell в этой папке.
3. Создайте виртуальное окружение:
   `py -3.12 -m venv .venv`
4. Активируйте его:
   `.\.venv\Scripts\Activate.ps1`
5. Установите зависимости:
   `python -m pip install --upgrade pip`
   `pip install -r requirements.txt`
6. Запустите:
   `python main.py`

Данные приложения сохраняются в `%LOCALAPPDATA%\DocuMind`:
- `rules.json` — правила анализа;
- `documind.sqlite3` — история обработки;
- `logs\documind.log` — журнал ошибок.

## Сборка EXE (после успешного тестирования)
В активированном окружении:
`pyinstaller --noconfirm --clean --windowed --name DocuMind main.py`

Перед распространением EXE обязательно проверить запуск на чистой Windows-машине. Эта сборка не включает OCR и не является ИИ-моделью.

## Тесты
`python -m unittest discover -s tests -v`

Тесты используют временные каталоги и не меняют пользовательские документы.

## Ограничения тестовой сборки
- OCR сканированных PDF не реализован.
- Старые файлы DOC (не DOCX) не поддерживаются.
- Анализ реквизитов зависит от текста и правил; точность не гарантируется.
- Качество краткой выжимки базовое, без LLM.
- Формат существующего Excel-реестра может отличаться от ожидаемого; перед работой с важным реестром сделайте копию.
- ZIP содержит исходный код, а не готовый EXE.
