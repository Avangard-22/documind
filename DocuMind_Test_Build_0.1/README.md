 # DocuMind 0.2 — тестовая сборка для Windows

DocuMind — настольный инструмент для извлечения текста из документов, базового анализа реквизитов и экспорта в Excel. Этот ZIP содержит исходники, а не готовый Windows EXE.

## Что добавлено в 0.2
- Поддержка файлов `.eml` и `.msg` наряду с PDF, DOCX и XLSX.
- Извлечение метаданных электронного письма: отправитель, получатель, копия, тема, дата и Message-ID, если они доступны.
- Очистка HTML-тела письма и обнаружение метаданных вложений.
- Попытка OCR для PDF-страниц с малым количеством извлечённого текста.
- Сохранение полного извлечённого текста и метаданных письма в SQLite.
- Расширенный структурированный анализ: отправитель, получатель, тема, предполагаемые действия, срок, необходимость ответа и отметка ручной проверки.
- Excel с листами `Реестр`, `Полные тексты` и `Вложения`.
- Миграция существующей SQLite-базы v0.1 при запуске.
- Дополнительные автоматические тесты.

## Важные ограничения этой тестовой версии
- Это **не полноценная языковая модель**. Смысловые поля формируются осторожными эвристиками и правилами; их нужно проверять на реальных письмах.
- Вложения EML/MSG пока перечисляются в листе `Вложения`, но их содержимое не извлекается автоматически как отдельные документы.
- Для OCR требуется не только Python-пакет `pytesseract`, но и установленный системный Tesseract OCR с языковыми данными. Для русского языка нужен пакет `rus`; путь к `tesseract.exe` может потребоваться настроить.
- OCR работает только для PDF-страниц в этом выпуске; отдельные изображения и сканы внутри DOCX не обрабатываются.
- Старый формат Word `.doc` не поддерживается.
- Не открывайте вложения из недоверенных источников автоматически. Этот выпуск не запускает вложения, но последующую обработку следует проводить с ограничениями размера и типов.
- XLSX может содержать очень длинный текст; Excel имеет ограничение 32 767 символов на одну ячейку. Очень длинные письма следует дополнительно сегментировать в следующем патче.
- Сборка EXE и GUI не проверялись на реальной Windows-машине в этой среде.

## Установка и запуск из исходников
1. Установите Python 3.12 для Windows.
2. Распакуйте ZIP в обычную папку, например `C:\Tools\DocuMind`.
3. Запустите `install_and_run.bat` или выполните команды:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

Данные приложения хранятся в `%LOCALAPPDATA%\DocuMind`.

## Тесты

```bat
.venv\Scripts\python -m unittest discover -s tests -v
```

## Сборка EXE

Локально, в активированном `.venv`, запустите `build_exe.bat`. В GitHub Actions используйте workflow в `.github/workflows/build-windows.yml`. Сборку необходимо проверить на Windows перед рабочим применением.

## Рекомендуемый сценарий испытаний
1. Создайте копию папки с документами и тестового Excel.
2. Возьмите несколько PDF с текстом, сканов, DOCX, EML и MSG без конфиденциальных данных.
3. Сверьте извлечённые реквизиты и полные тексты с оригиналами.
4. Проверьте листы Excel и отсутствие дубликатов после повторной обработки.
5. Проверьте OCR отдельно после установки Tesseract.
